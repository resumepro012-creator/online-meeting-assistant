#  - Nothing is downloaded at import time: weights are fetched the first time a
#    model is actually used, then cached locally (see HF_HOME / model cache dir).
#  - Support for these libraries on Python 3.14 is limited; use Python 3.11.
# -----------------------------------------------------------------------------
